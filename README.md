# 🛍️ ShopEase - E-Commerce Store

ShopEase is a full-stack e-commerce web application built using Django, HTML, CSS, JavaScript and SQLite.

## 🚀 Features

- User Registration and Login
- Product Listings
- Product Details
- Product Images
- Shopping Cart
- Increase / Decrease Cart Quantity
- Remove Products from Cart
- Stock Management
- Checkout System
- Order Processing
- Order History
- Django Admin Panel
- Responsive User Interface
- Animated Modern UI

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
- Pillow
